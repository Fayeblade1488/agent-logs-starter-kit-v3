# Security Policy

## Supported Versions

This project is a starter kit, and security fixes are applied directly to the `main` branch. We recommend users pull the latest changes from `main` to receive all updates, including security patches.

| Branch | Supported          |
| ------ | ------------------ |
| `main` | :white_check_mark: |

## Reporting a Vulnerability

We take all security vulnerabilities seriously. If you discover a security issue, please report it to us privately. **Do not** create a public GitHub issue.

Please send an email to **[INSERT PREFERRED SECURITY EMAIL ADDRESS]** with the following information:

-   A description of the vulnerability and its potential impact.
-   Steps to reproduce the issue.
-   Any proof-of-concept code, screenshots, or logs.

You can also use GitHub's private vulnerability reporting feature by clicking the "Report a vulnerability" button on the "Security" tab of the repository.

We will do our best to respond to your report within 48 hours and will keep you informed of our progress as we work to resolve the issue. We appreciate your efforts to disclose vulnerabilities responsibly.
